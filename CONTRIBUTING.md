# Contributing to Artificial Stupidity

## The rules

1. **Must be deliberately dumb** — if it tries to be helpful, it doesn't belong here
2. **Must be surprisingly useful** — if it's just annoying, it doesn't belong here
3. **One tool per folder** — `your-tool-name/index.mjs` + `package.json` + `README.md`
4. **CLI first** — keep it simple, terminal-based
5. **Any language** — Node, Python, Bash, whatever works

## What fits

- Tools that make you do the thinking
- Tools that generate bad versions of things
- Tools that ask uncomfortable questions
- Tools that simulate cognitive biases
- Tools that force constraints

## What doesn't fit

- Normal AI assistants
- Actually helpful tools
- Anything that solves your problem for you

## How to submit

Fork → add your tool in its own folder → PR with a one-line description of "why is this stupid?" and "why is this useful?"
