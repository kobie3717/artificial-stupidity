# Scope Explosion Bot

**The AI that forces you to discover your actual requirements by refusing to do the simple version.**

Tell it "add a login button" and watch it architect a 17-step enterprise SSO integration with audit logging, microservices, and a Phase 2 roadmap. Then argue it down to reality.

## Why

Because sometimes the best way to figure out what you *actually* need is to fight someone who insists you need way more.

## Install

```bash
cd scope-explosion-bot
npm install
cp .env.example .env
# Add your ANTHROPIC_API_KEY to .env
```

## Run

```bash
npm start
```

Type your simple request. Bot explodes the scope. You push back. Bot doubles down. After 3 rounds, it finally gives you the one-sentence version of what you actually wanted.

Repeat until enlightened.
